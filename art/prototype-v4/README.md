# Player identity pass

Preserved pre-edit source and native body sheet from the physical-profile build.
The current editable art is generated by `scripts/player-poses.mjs` and
`scripts/create-prototype-art.mjs` into the native project.

The update gives the crew distinct eight-pixel heads: MATUS spikes/goatee,
MAGIC glasses and clean jaw, BAMBI round face/beard, TORRES cropped hair/full
beard, CHOMPA green beanie/glasses, and MEAT's approved invented short-haired look.
Standing builds and confirmed heights remain intact. Gather/landing share native
cells to reserve space for six readable jersey markers without exceeding VRAM.

Sprite hardware color zero is transparent. `jam_look.c` applies actual skin to
visible color one and the team kit to color two. Authored GB Studio sprite
palettes use their first two visible entries; the CLI inserts the transparent
entry in the compiled OBJ palette. Runtime color uploads and authored palette
resources therefore use different indexing conventions deliberately.

The marker identifies the controlled player by jersey number; the HUD gives the
full name and jersey. Approved 32×32 scouting portraits remain unchanged.
