Later sampled frames show repeated alternation between the court and corrupted imagery, with the HUD still corrupted. The second clean-boot replay reached the same later failure; the original recording establishes the illustrated transition. Exact onset and duration between the 30-frame samples were not measured.

**Observed:** The sampled court at frame 13380 is followed by a full-screen pink/garbled image at frame 13410. The identical image remains at frames 13818, 15618, and 15738, including after SELECT. The exact same frame hash recurred on a second clean boot with the same input sequence. No final result or usable pause screen appeared. **Expected:** The match continues to the period ending and results, and SELECT opens the pause controls during live play.
